# AI_Course

This repository contains homeworks from my **Artificial Intelligence** course at university.

---
## 1: Shortest Path from Arad to Bucharest

Implement various search algorithms from scratch and compare their performance in finding a car's path on a map. You must design a graph of cities and roads, implement the search algorithms, and evaluate their performance.

---
## 2: Game with Minimax and Alpha-Beta Pruning

Implement a game from scratch that is played on a 10×10 grid with three players: two human players and one robot (AI). The robot must act intelligently using the Minimax algorithm with Alpha-Beta pruning.

---
## 3: Skyscraper

implement an algorithm that processes an array of numbers, where each number represents the height of a skyscraper. The goal is to compute a property of the skyline formed by these buildings.

---

## 4: Image Processing Operations

Implement four fundamental image processing operations using OpenCV and provide an interactive menu for the user to apply them to an input image:

1. **Thresholding**: Binary and Adaptive Mean thresholding.
2. **Mean Filter**: 5×5 blurring.
3. **Geometric Transformation**: Rotation and scaling.
4. **Noise Addition**: Salt and pepper noise (10% salt, 20% pepper).
